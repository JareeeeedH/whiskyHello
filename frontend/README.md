# WhiskyHello Frontend

Vue 3 + Vite + TypeScript frontend for WhiskyHello.

## Stack

- Vue 3
- Vite
- TypeScript
- Vue Router
- Pinia
- Axios
- PrimeVue 4

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

- `npm run dev` — start Vite development server
- `npm run build` — type-check and production build
- `npm run preview` — preview production build
