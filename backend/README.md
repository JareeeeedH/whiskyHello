# WhiskyHello Backend

Node.js + Express + TypeScript API for WhiskyHello.

## Stack

- Node.js
- Express
- TypeScript
- MongoDB / Mongoose
- JWT
- Joi

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

- `npm run dev` — start development server with hot reload
- `npm run build` — compile TypeScript to `dist/`
- `npm start` — run compiled server
