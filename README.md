# WhiskyHello 🥃

威士忌探索、評論與未來 AI 個人化體驗平台。

WhiskyHello 是原 WhiskyFun 專案的重新建構版本，主要聚焦於威士忌探索、使用者評論，以及未來的個人化與 AI 體驗。

---

## 專案概述

WhiskyHello 採階段式方式開發。

### Phase 1｜基礎產品

- 威士忌搜尋／知名評論家評論
- 使用者評論／評分
- 會員／個人資料
- Whisky News／最新資訊

### Phase 2｜AI

- AI Whisky Sommelier
- 個人化威士忌推薦
- 推薦原因說明

### Phase 3｜交易媒合

- 酒款買賣媒合
